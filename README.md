## 📋 Описание

Репозиторий содержит **практические работы по дисциплине "Численные методы"**.

В рамках курса выполнялись задания, связанные с изучением **численных алгоритмов** и методов решения математических задач.  
Часть работ включало в себя **реализацию алгоритмов с использованием программного кода на языке программирования Python**.

---

## 📚 Содержимое репозитория

Практические работы могут включать:

* решение математических задач численными методами;
* реализацию алгоритмов на языке программирования;
* анализ и проверку полученных результатов;
* отчёты и материалы по практическим работам.
